# Beyond CV Chrome Extension Demo

这是一个可以安装到 Chrome / Edge 的开发版扩展。它会在招聘网站页面中扫描表单字段，按候选人资料生成匹配建议，并在用户确认后填入已选字段。扩展不会自动提交申请，也不会自动勾选协议、隐私、证件、薪资等敏感字段。

## 安装方式

1. 解压 `beyond-cv-extension.zip`。
2. 打开 `chrome://extensions`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择解压后的 `beyond-cv-extension` 文件夹。

如果要在本地 `file://` 原型页面上测试，请在扩展详情页开启「允许访问文件网址」。在真实招聘网站上使用时不需要这个开关。

## 使用方式

1. 打开一个招聘网站申请表页面。
2. 点击浏览器工具栏里的 Beyond CV 图标。
3. 点击「扫描」，查看字段匹配结果。
4. 取消不想填入的字段。
5. 点击「填入已选字段」，再回到网页人工检查。
6. 在完成一次投递或进入投递流程时，确认公司和岗位，点击「记录本次投递」。记录会同步到 Beyond CV 页面里的「投递管理」。

如果招聘网站的字段结构比较复杂，扫描结果显示 0 匹配，可以点击「按页面字段直填」。该模式会先把网页转换成字段模型，优先读取页面 DOM 里的 `label`、`aria`、placeholder、name/id 和表单项容器；只有 DOM 语义不足时，才用可见字段名和位置关系兜底。当前会直接写入姓名、手机、邮箱、教育起止时间、学校、学历、学院、专业等字段。

如果已经在 Beyond CV 操作页面创建账户并同步简历，可以在插件弹窗输入同一账户邮箱和密码，点击「登录账户」，再点击「从云端同步资料」。插件会把后端 profile 写入本地资料，后续扫描和直填都会使用这份最新数据。也可以继续使用同步码作为兜底导入方式。

## 资料来源

扩展默认带一份演示资料。你可以在扩展弹窗点击「编辑」修改，也可以在 Beyond CV 原型页面上点击「从 Beyond CV 页面导入资料」。

## 当前边界

- 支持常见 input、textarea、select、contenteditable 字段。
- 支持中文和英文常见字段名。
- 对第三方复杂 iframe、验证码、上传简历、题库式动态组件不做自动提交。
- 敏感字段默认只标记，不批量填入。
