## Comment 2：大屏幕下 A4 预览区域比例异常

位置：`beyond-cv-prototype.html`，`.resume-workbench` / `.resume-preview-sticky`

问题：
- 高分辨率下左侧预览列被拉得过宽，A4 页面保持 520px 宽度但外层面板占据大量空白。
- 视觉上会误以为预览区错位或缩放异常。

处理：
- 为 `.resume-workbench` 增加 `max-width: 1120px` 和居中布局。

状态：已处理。需要在大屏刷新页面复核。

## 插件匹配不上字段

截图现象：
- 插件已经能注入页面并框出待填字段。
- 但教育经历表单里「学校名称」「学院」「专业」「起止时间」等字段显示「未匹配」。
- popup 只显示 `1 可填 / 40 字段`，说明问题不在插件连接，而在字段标签抽取和匹配词典。

原因判断：
- 原 content script 主要依赖 `aria-label`、`placeholder`、`name/id`、最近容器文本。
- 真实招聘网站的字段标签经常是 input 前面的兄弟节点或上层 form item 标题，不一定和 input 直接绑定。
- 词典缺少教育类字段，如「学历类型」「学院」「实验室」「研究方向」「导师」「起止时间」。
- popup 把“已识别但本地资料缺值”的字段也显示成「未匹配」，误导调试。

处理：
- 扩展字段标签抽取升级为读取：
  - `aria-label`
  - `aria-labelledby`
  - `label[for]`
  - 包裹式 `label`
  - 常见 form item 容器
  - input 前置兄弟节点和上层兄弟节点
  - `placeholder`、`title`、`data-label`、`name/id`
- 教育字段词典新增：
  - 教育起始时间
  - 教育结束时间
  - 学历类型
  - 学校名称
  - 学院
  - 学位
  - 专业
  - 实验室
  - 研究方向
  - 导师
- 插件资料新增：
  - `educationType`
  - `educationStart`
  - `educationEnd`
  - `college`
  - `lab`
  - `researchArea`
  - `advisor`
- popup 统计改为 `可填 / 已识别 / 总字段`。
- 页面标记改为区分：
  - `Beyond CV: 字段名`：已识别且可填
  - `资料缺失: 字段名`：已识别但本地资料没值
  - `未匹配`：没有识别到字段类型

状态：已处理，并已重新打包 `beyond-cv-extension.zip`。
