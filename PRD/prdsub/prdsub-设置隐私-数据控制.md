# Beyond CV 页面 PRD：设置隐私 - 数据控制

## 1. 页面概述

| 字段 | 内容 |
|-----|------|
| 页面名称 | 设置与隐私 |
| 所属模块 | 账号与资料安全 |
| 页面路由 | `/settings/privacy` |
| 页面优先级 | P0 |
| 主要用户 | 已登录求职者 |
| 前置依赖 | 用户已登录 |
| 后置页面 | 个人经历库、插件、账号管理 |

设置与隐私页面负责建立用户对 Beyond CV 的长期信任。因为产品会保存家庭信息、成绩、联系方式、求职动机等敏感资料，用户必须能清楚知道哪些资料会被 AI 使用、哪些会被插件填入，以及如何导出或删除。

## 2. 产品目标

- 让用户集中管理隐私开关。
- 支持查看和控制敏感字段参与 AI 生成、插件填表。
- 支持数据导出和删除账号。
- 支持插件连接管理。
- 明确说明资料默认私有。

## 3. 页面布局

采用设置页常见两栏布局：

- 左侧设置导航：账号、安全、隐私、插件、数据导出、删除账号。
- 右侧当前设置详情。

隐私页顶部必须显示总说明：

“你的资料默认仅自己可见。Beyond CV 不会自动向企业公开你的资料，也不会自动提交申请。”

## 4. 页面元素

| 区域 | 元素 | 类型 | 说明 |
|-----|------|------|------|
| 顶部 | 隐私总开关说明 | 信息块 | 强调默认私有 |
| 隐私控制 | AI 使用资料范围 | 开关组 | 控制各类资料是否参与生成 |
| 隐私控制 | 插件填表范围 | 开关组 | 控制各类资料是否可被插件建议填入 |
| 敏感字段 | 敏感字段列表 | 表格 | 家庭信息、GPA、联系方式等 |
| 插件管理 | 已连接浏览器 | 列表 | 显示连接状态和最近使用 |
| 数据管理 | 导出数据 | 按钮 | 导出 JSON/Markdown，MVP 可先定义 |
| 数据管理 | 删除资料/账号 | 危险按钮 | 二次确认 |

## 5. 隐私开关

### 5.1 AI 使用资料范围

| 资料类型 | 默认状态 | 说明 |
|---------|---------|------|
| 基础信息 | 开启 | 用于简历和官网字段 |
| 教育经历 | 开启 | 用于简历和岗位适配 |
| 实习经历 | 开启 | 用于简历和开放题 |
| 校园经历 | 开启 | 用于 leadership/teamwork |
| 技能证书 | 开启 | 用于短答和简历 |
| 家庭信息 | 关闭 | 敏感，仅在用户明确开启后参与 |
| GPA/成绩 | 关闭或由用户选择 | 敏感，默认谨慎 |
| 开放题素材 | 开启 | 用于 behavior question |

### 5.2 插件填表范围

| 资料类型 | 默认状态 | 说明 |
|---------|---------|------|
| 姓名/联系方式 | 开启 | 高频字段 |
| 教育经历 | 开启 | 高频字段 |
| 实习经历 | 开启 | 高频字段 |
| 家庭信息 | 关闭 | 必须确认 |
| Consent | 关闭 | 不自动同意 |
| Cover Letter | 开启 | 但填入前用户确认 |
| Behavior Question | 开启 | 但填入前用户确认 |

## 6. 交互逻辑

### 6.1 修改隐私开关

1. 用户进入隐私设置。
2. 切换某类资料参与范围。
3. 若关闭，系统立即保存。
4. 若开启敏感字段，弹出说明。
5. 用户确认后生效。

### 6.2 导出数据

1. 用户点击“导出我的数据”。
2. 选择导出范围：全部资料、经历库、岗位材料、简历版本。
3. 系统生成文件。
4. 用户下载。

### 6.3 删除资料或账号

1. 用户点击删除。
2. 系统展示影响范围。
3. 用户输入确认文本，例如 DELETE。
4. 系统执行删除。
5. 删除完成后退出登录。

## 7. 异常与边界

| 异常场景 | 处理方式 |
|---------|---------|
| 保存设置失败 | 回滚开关并提示重试 |
| 导出失败 | 保留请求状态，允许重试 |
| 删除失败 | 不退出登录，显示错误 |
| 插件连接异常 | 显示重新连接入口 |
| 开启敏感字段 | 必须二次确认 |

## 8. 前端设计要求

- 危险操作必须视觉区分，但不要误触。
- 隐私说明用清晰人话，不写冗长法务文本。
- 开关项旁边要说明影响范围，例如“关闭后 cover letter 不会引用 GPA”。
- 敏感字段表格应可按类型筛选。
- 删除账号入口放在页面底部危险区域。

## 9. 埋点需求

| 事件名 | 触发时机 | 属性 |
|-------|---------|------|
| privacy_view | 进入页面 | user_id_hash |
| privacy_toggle_ai | 切换 AI 使用范围 | data_type、enabled |
| privacy_toggle_extension | 切换插件填表范围 | data_type、enabled |
| privacy_export | 点击导出 | export_scope |
| privacy_delete_start | 点击删除 | delete_type |
| privacy_delete_confirm | 确认删除 | delete_type |

## 10. 验收标准

- 用户可以查看和修改每类资料的 AI 使用权限。
- 用户可以查看和修改每类资料的插件填表权限。
- 敏感字段开启时有二次确认。
- 页面明确说明资料默认私有且不自动提交申请。
- 删除和导出入口可用且不会误触。
