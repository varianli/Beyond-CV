# Beyond CV 页面 PRD：简历生成 - 编辑预览

## 1. 页面概述

| 字段 | 内容 |
|-----|------|
| 页面名称 | 简历生成器 |
| 所属模块 | 简历生成 |
| 页面路由 | `/resume`、`/resume/:id` |
| 页面优先级 | P0 |
| 主要用户 | 需要生成一页式中英文简历的求职者 |
| 前置依赖 | 用户至少有基础信息、教育经历、一段实习/校园经历 |
| 后置页面 | 岗位适配、导出、插件填表 |

简历生成器基于用户提供的顶级公司通用模板，生成严格一页式简历。核心体验不是模板市场，而是“从经历库中选择最相关内容，实时看到排版变化，并在一页内保持专业可读”。

## 2. 产品目标

- 支持中文和英文简历版本。
- 支持从经历库勾选教育、实习、校园、技能等内容。
- 支持推荐最多 3 段实习经历，避免内容堆砌。
- 实时预览用户选择和编辑造成的版面变化。
- 自动调整字号、行距和段落密度，但不牺牲基本可读性。

## 3. 页面布局

### 3.1 桌面端布局

采用三栏工作台：

- 左栏：版本设置和经历选择。
- 中栏：内容编辑器。
- 右栏：A4 简历实时预览。

右侧预览应固定显示，滚动页面时仍可看到当前简历。预览区域不放在装饰卡片里，应像真实文档画布。

### 3.2 移动端布局

移动端不作为主要编辑场景，MVP 支持查看和轻量修改：

- 顶部 Tab：选择内容 / 编辑内容 / 预览。
- 预览可缩放查看。
- 导出可延后到桌面端优先。

## 4. 页面元素

| 区域 | 元素 | 类型 | 说明 |
|-----|------|------|------|
| 顶部 | 简历名称 | 输入框 | 如 “IB Summer Analyst - English” |
| 顶部 | 语言版本 | 分段控件 | 中文 / English |
| 顶部 | 目标用途 | 下拉 | 通用、金融、咨询、法律、互联网 |
| 左栏 | 模板选择 | 单选 | MVP 只提供通用模板，后续扩展 |
| 左栏 | 经历勾选 | 复选列表 | 教育、实习、校园、技能 |
| 左栏 | 内容超限提示 | 状态条 | 显示一页适配状态 |
| 中栏 | Section 编辑器 | 表单/富文本 | 按 Education、Experience 等编辑 |
| 中栏 | AI 改写 | 按钮 | 改写 bullet 或压缩内容 |
| 右栏 | A4 预览 | 文档画布 | 实时显示排版 |
| 右栏 | 密度控制 | 滑杆/自动 | 舒适、标准、紧凑 |

## 5. 模板结构

### 5.1 英文模板

英文简历默认结构：

1. Name / Contact
2. EDUCATION
3. INTERNSHIP EXPERIENCE
4. LEADERSHIP EXPERIENCE
5. SKILLS, ACTIVITIES & INTERESTS

默认字体：Times New Roman。页面边距、字号、行距需保证一页内专业可读。标题使用大写英文，列表使用 bullet。

### 5.2 中文模板

中文简历默认结构：

1. 姓名 / 联系方式
2. 教育经历
3. 技能
4. 实习经历
5. 活动经历
6. 兴趣爱好及性格

默认字体：宋体。中文版本应保持简洁，避免因中文文本密度高造成堆叠。

## 6. 内容规则

| 内容 | 规则 |
|-----|------|
| 实习经历 | 默认推荐 3 段以内，超过时提示用户删减 |
| Bullet 数量 | 每段实习建议 2-4 条 |
| 英文 bullet | 推荐动词开头，强调动作、分析、结果 |
| 中文 bullet | 可按“工作模块 + 具体产出”组织 |
| GPA/成绩 | 敏感字段，用户可隐藏 |
| 照片 | P2，可显示开关和合规提示，MVP 可不进入模板 |
| 兴趣 | 英文版保持 1-2 行，中文可更自然但不冗长 |

## 7. 交互逻辑

### 7.1 新建简历

1. 用户进入 `/resume`。
2. 点击“新建简历”。
3. 选择语言和目标用途。
4. 系统从经历库推荐内容。
5. 用户勾选经历后生成初始预览。
6. 用户编辑内容并保存。

### 7.2 勾选经历

1. 用户在左栏勾选一段经历。
2. 中栏出现对应 Section 编辑块。
3. 右栏预览实时更新。
4. 若超出一页，系统先自动压缩。
5. 若仍超出，显示删减建议。

### 7.3 AI 改写/压缩

1. 用户选中一条 bullet。
2. 点击“改写”或“压缩”。
3. 系统生成 2-3 个备选版本。
4. 用户选择替换或手动编辑。
5. 替换后预览更新。

### 7.4 排版密度

密度档位：

- 舒适：可读性优先，适合内容少。
- 标准：默认。
- 紧凑：内容较多时使用。

当紧凑档仍无法一页容纳时，不再无限缩小字号，而是提示删减。

## 8. 版面状态

| 状态 | 页面表现 |
|-----|---------|
| 一页适配 | 顶部显示绿色“已适配一页” |
| 接近超限 | 显示黄色“内容较满，建议减少 1-2 条 bullet” |
| 超出一页 | 显示红色“已超出一页”，预览中标出溢出部分 |
| 字号过小 | 阻止继续压缩，并建议删减 |
| 无可用经历 | 引导用户去经历库补充 |

## 9. 异常与边界

| 异常场景 | 处理方式 |
|---------|---------|
| 经历库资料被删除 | 简历版本保留快照，并提示源资料不存在 |
| AI 改写失败 | 保留原文，提示重试 |
| 用户快速连续编辑 | 本地防抖保存，避免预览闪烁 |
| 预览渲染失败 | 显示重试和文本编辑区，不阻塞保存 |

## 10. 前端设计要求

- 预览区必须接近真实 A4 比例。
- 勾选、编辑、预览之间反馈要即时。
- 不要用过大的标题或营销式文案，页面是生产工具。
- 操作按钮使用图标辅助，例如 Save、Download、RefreshCw、WandSparkles。
- 文档画布和编辑栏之间要有明确视觉分隔。

## 11. 验收标准

- 用户可从经历库生成中文或英文简历。
- 勾选经历后预览实时更新。
- 超出一页时有明确提示和删减建议。
- 实习经历超过 3 段时给出行业惯例提示。
- AI 改写不会直接覆盖原文，必须用户确认。
