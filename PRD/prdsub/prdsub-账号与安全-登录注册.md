# Beyond CV 页面 PRD：账号与安全 - 登录注册

## 1. 页面概述

| 字段 | 内容 |
|-----|------|
| 页面名称 | 登录注册页 |
| 所属模块 | 账号与资料安全 |
| 页面路由 | `/auth`、`/auth/login`、`/auth/register` |
| 页面优先级 | P0 |
| 主要用户 | 首次使用或回访的求职者 |
| 前置依赖 | 无 |
| 后置页面 | 首次建档页 `/onboarding` 或首页工作台 `/dashboard` |

本页面负责让用户快速进入 Beyond CV，并在首次使用前建立“资料私有、安全可控”的心智。登录注册不是营销落地页，首屏应直接服务进入产品，不使用大段宣传式 hero。页面需要安静、可信、效率优先，让用户感到这是一个会保存大量敏感求职资料的专业工具。

## 2. 产品目标

- 支持用户创建账号、登录账号、找回密码。
- 明确告知用户资料默认私有，不会自动公开给企业或第三方。
- 首次登录后引导用户进入建档流程。
- 回访登录后根据资料完成度进入首页工作台。

## 3. 用户故事

| 编号 | 用户故事 | 优先级 |
|-----|---------|--------|
| US-AUTH-01 | 作为新用户，我希望用邮箱或手机号创建账号，以便保存长期求职资料 | P0 |
| US-AUTH-02 | 作为回访用户，我希望快速登录并继续编辑我的资料库 | P0 |
| US-AUTH-03 | 作为用户，我希望知道我的资料不会自动公开给公司 | P0 |
| US-AUTH-04 | 作为忘记密码的用户，我希望可以重置密码 | P1 |

## 4. 页面布局

### 4.1 桌面端布局

页面采用左右两栏，但左侧不是营销海报。推荐布局：

- 顶部：Beyond CV 标识、语言切换、隐私说明入口。
- 左侧 40%：产品安全承诺和当前流程说明。
- 右侧 60%：登录/注册表单卡片。
- 底部：服务条款、隐私政策、版本号。

左侧内容只保留三点：

- “你的资料默认仅自己可见”
- “AI 生成内容使用前由你确认”
- “招聘官网提交动作由你完成”

### 4.2 移动端布局

- 顶部显示产品名和安全说明入口。
- 登录/注册表单置顶。
- 安全承诺折叠在表单下方。
- 表单按钮宽度铺满，输入框高度不低于 44px。

## 6. 字段规则

| 字段 | 校验规则 | 错误提示 |
|-----|---------|---------|
| 邮箱 | 必须符合邮箱格式 | 请输入有效邮箱地址 |
| 手机号 | 若启用，按地区校验 | 请输入有效手机号 |
| 密码 | 8-32 位，至少包含字母和数字 | 密码需包含 8 位以上字母和数字 |
| 验证码 | 6 位数字或后端配置 | 验证码格式不正确 |
| 服务协议勾选 | 注册时必须勾选 | 请阅读并同意服务条款与隐私政策 |

## 7. 交互逻辑

### 7.1 注册流程

1. 用户进入 `/auth/register`。
2. 输入邮箱、密码并勾选协议。
3. 点击“创建账号”。
4. 前端进行格式校验。
5. 校验通过后调用注册接口。
6. 注册成功后进入 `/onboarding`。
7. 系统在本地记录首次建档状态为 `not_started`。

### 7.2 登录流程

1. 用户进入 `/auth/login`。
2. 输入邮箱和密码。
3. 点击“登录”。
4. 登录成功后请求用户资料完成度。
5. 若资料完成度低于 30%，进入 `/onboarding`。
6. 若已有资料库，进入 `/dashboard`。

### 7.3 找回密码流程

1. 点击“忘记密码”。
2. 输入邮箱。
3. 系统发送重置链接或验证码。
4. 用户设置新密码。
5. 完成后返回登录页。

## 8. 状态设计

| 状态 | 页面表现 |
|-----|---------|
| 默认态 | 登录表单可填写，主按钮可点击 |
| 输入错误 | 对应输入框红色边框，下方显示错误 |
| 提交中 | 主按钮显示 loading，表单不可重复提交 |
| 登录失败 | 表单顶部显示错误条，不清空已输入邮箱 |
| 注册成功 | 进入首次建档，不弹营销弹窗 |
| 网络异常 | 提示“网络异常，请稍后重试”并保留输入 |

## 9. 权限与安全

- 登录态 token 应安全存储，避免明文暴露。
- 用户密码不在前端日志中输出。
- 错误提示不应暴露账号是否存在的过多细节。
- 注册时必须展示隐私政策入口。
- 默认不开启“企业可见”或“公开资料”。

## 10. 埋点需求

| 事件名 | 触发时机 | 属性 |
|-------|---------|------|
| auth_page_view | 进入页面 | source、mode |
| auth_register_submit | 点击注册 | method |
| auth_register_success | 注册成功 | method |
| auth_login_submit | 点击登录 | method |
| auth_login_success | 登录成功 | profile_completion |
| auth_error | 登录/注册失败 | error_code、mode |

## 11. 验收标准

- 用户可以完成注册并进入首次建档页。
- 已有账号可以登录并进入对应后置页面。
- 表单错误有明确提示，且不会造成重复提交。
- 页面明确展示资料默认私有的提示。
- 移动端不出现按钮文字溢出或输入框重叠。
